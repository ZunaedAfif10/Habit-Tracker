## 🌿 HabitFlow – Habit Tracker

A simple and attractive Habit Tracker application built with React and Vite to help users build good daily habits and track their progress.

## 🔗 Live Demo
https://habit-tracker-blond-delta.vercel.app

## 🚀 Features
- Add new habits
- Mark habits as completed
- Delete habits
- Track daily progress
- Save habits using localStorage

## 🛠️ Technologies
- React.js
- Vite
- Tailwind CSS
- shadcn/ui
- useState
- useEffect
- useNavigate

## 💻 Installation
```bash
npm install
npm run dev
